Generated from `package.json`, build configs, source imports, and repository layout. Versions are package.json specifiers; lockfile resolution is governed by `bun.lock`.

## Languages and Runtimes

| Technology           | Role in this project                                                                                |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| TypeScript           | Main language for Electron main process, preload scripts, React renderer, tests, and build scripts. |
| TSX/React JSX        | Renderer component language for the desktop/WebUI interface.                                        |
| JavaScript / Node.js | Runtime substrate for Electron, scripts, and generated/bundled helpers.                             |
| Bun                  | Package manager and command runner; also provides the optional `bun:sqlite` database driver.        |
| HTML/CSS             | Renderer entry documents, desktop pet pages, themes, Arco overrides, and UnoCSS output.             |
| SQLite SQL           | Local persistence schema, migrations, indexes, and repository queries.                              |

## Build and Configuration Technologies

| Technology                      | Role                                                                                             |
| ------------------------------- | ------------------------------------------------------------------------------------------------ |
| electron-vite config            | Builds main, preload, renderer, pet windows, static assets, source maps, and MCP server bundles. |
| Vite standalone renderer config | Builds `out/renderer` for WebUI/server deployments without Electron.                             |
| UnoCSS config                   | Defines semantic colors, Arco color compatibility rules, and utility shortcuts.                  |
| Vitest projects                 | Separates Node tests and jsdom React tests with shared aliases and setup files.                  |
| Dockerfile                      | Container/server build path for WebUI/server mode.                                               |
| GitHub remote                   | Push target is `https://github.com/Antman1526/AionUi-Twin.git`.                                  |

## Notable Transitive Build Utilities

| Technology        | Role in this project                                                                                                                                       |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `minimatch`       | Glob matcher used by Electron Builder/app-builder-lib to evaluate `electron-builder.yml` file include/exclude patterns during installer creation.          |
| `brace-expansion` | Transitive `minimatch` dependency pinned through `resolutions`/`overrides` to `^2.0.2`; v5 lacks the default export shape expected by this build pipeline. |
